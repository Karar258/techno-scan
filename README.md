# TECHNO SCAN

تطبيق عربي لإدارة كتالوج المتجر، صور المنتجات وأسعارها ومقاساتها وألوانها وتوفرها، مع صفحة عامة ورمز QR مستقل لكل منتج.

## التشغيل المحلي

```sh
npm install
npm run dev
```

## البناء والنشر على Cloudflare Pages

```sh
npm run build
```

اربط المستودع بمشروع Cloudflare Pages واستخدم الإعدادات التالية:

- **Build command:** `npm run build`
- **Build output directory:** `dist`
- **Node.js version:** 20 أو أحدث

يتضمن `public/_redirects` قاعدة SPA لتمرير المسارات مثل `/p/linen-shirt` إلى التطبيق، وتُنسخ تلقائياً إلى `dist/_redirects` عند البناء.

## ملاحظات النسخة الحالية

- تسجيل الدخول تجريبي فقط: يُحفظ اسم صاحبة المتجر في المتصفح ولا توجد خدمة حسابات أو مصادقة خلفية.
- المنتجات وإعدادات المتجر تُحفظ في `localStorage` على الجهاز الحالي؛ لا توجد مزامنة للكتالوج بين الأجهزة.
- يحتوي رابط QR على تفاصيل المنتج الأساسية حتى تعمل الصفحة العامة على جهاز العميل. تُضمّن صورة المنتج إذا كانت متاحة عبر رابط عام؛ الصور المرفوعة من الجهاز لا تنتقل عبر الرابط، وتتطلب تخزيناً خلفياً لعرضها على أجهزة أخرى.
- هذه النسخة لا تتصل بالكاشير أو بنظام دفع.
